## F02 持续机会清单及排序快照

同一 OP-ID 持续使用；新增排序另存快照，保留旧顺位。本表不是预购清单。可先填多个候选，再对短名单补技术细节。

| OP-ID/业务线/流程/负责人 | 候选切片：渠道×意图×主记录系统 | 高量（件数/频次/来源） | 可切窄 | 对错可判（判据/人） | 证据可测（数据/路径） | 客户关键人可投入（时段/替补） | 阻断/未知及责任人 |
|---|---|---|---|---|---|---|---|
| 【待填】 | | | | | | | |

| OP-ID | 主/次价值 | 基线与量化假设/区间/单位/窗口/来源 | 新增投入/复用及依赖 | 非AI替代比较 | 不作为影响/不确定性 | 当前价值确认人 |
|---|---|---|---|---|---|---|
| 【待填】 | | | | | | |

| 排序快照版本/日期 | OP-ID/旧名次→新名次 | 状态：候选/入选/暂缓/不适合/转化 | 选择/变化理由 | 依赖UC/公共能力 | 下次复评时间/触发 | UC/DP/B关联 | 批准人与证据 |
|---|---|---|---|---|---|---|---|
| 【待填】 | | | | | | | |

排序方法【待填】：先排除当轮不可启动项，再比较价值区间、投入、证据质量及依赖；若用加权分，记录权重及批准，不将不同单位直接相加。高量是筛选因素；高损失低频用例若拟例外入选，须专门说明测量可行性、风险与授权，不能伪装满足原条件。
